# Private Affiliate Network

Top-tier affiliate brand presentation built with Next.js, React, TypeScript, and Tailwind CSS.

## Positioning

This project is structured as a premium launch-ready site for a private affiliate network focused on:

- direct deals
- selective partner access
- offer intelligence
- traffic governance
- performance infrastructure

## Routes

- `/` — Overview
- `/capabilities` — commercial and operating capabilities
- `/infrastructure` — systems, governance, and scaling logic
- `/access` — access desk, entry flow, and FAQ

## Assets

Only one static asset is used:

- `public/bg.png`

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
